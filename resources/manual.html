仪器定位与诚实边界：
本工具为 100% 本机离线运行的确定性度量与辅助分析仪器，不上传任何用户数据。所有统计、敏感凭证嗅探与高亮均基于公开透明的数学公式与编码规则（Luhn 模 10 校验、ISO 7064:1983.MOD 11-2、香农信息熵），结果仅供本地安全排查与核验参考。

一、核心特性与 30 秒“诶”点

  • SHA-256 智能去重归档：剪贴板重复内容秒级识别去重，保留最新时间戳与历史引用。
  • 真实银行卡 Luhn 模 10 校验：杜绝正则假误报，严格校验 13~19 位卡号奇偶加权求和，排除全同测试伪号。
  • 二代身份证 ISO 7064 校验码校验：精准校验前 17 位生日/地域码与第 18 位校验码对应关系。
  • API Key 与 JWT 令牌嗅探：自动捕捉 OpenAI / AWS / GitHub Token 及 JWT 头部凭据。
  • 香农信息熵随机密码探针：利用数学信息熵公式 \(H = -\sum p_i \log_2 p_i\)，高敏捕获 \(H \ge 3.85\) 的极高危复杂密码。
  • 一键安全脱敏：保留前 3 字符与后 2 字符，中间自动填充 •••••• 掩码，防拍照防窥屏。

二、技术指标规格

指标项规格参数说明
离线保障100% 离线，无网络通信不向任何外部服务器发送剪贴板数据
哈希引擎SHA-256单条记录内容唯一数字指纹
卡号校验Luhn 模 10 算法真实数学求和 mod 10 === 0

脱敏规则前 3 字符 + •••••• + 后 2 字符结构保留但凭据无法还原

三、快捷操作与使用方法

  1. 启动软件即自动载入包含各类凭证的演示样本，直观展现 30 秒“诶”点；
  2. 点击上方“从系统剪贴板读取”按钮，实时抓取当前操作系统剪贴板内容并进行 SHA-256 归档与安全体检；
  3. 点击敏感条目右侧的“一键掩码复制”按钮，即可将脱敏后的安全版本重新拷入剪贴板；
  4. 点击右上角“导出 JSON 报告”可归档当前所有考古记录及其检测详情。
