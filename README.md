# 剪贴板考古台 (Clipboard Archaeology) v1.0.0

> 本地剪贴板历史检索与敏感信息防泄漏哨兵：支持 SHA-256 去重归档、全文检索、银行卡 Luhn 模 10 校验、二代身份证 ISO 7064 校验码、API 密钥/JWT 令牌解析、香农信息熵高危密码探针与一键安全掩码。

---

## 🎯 它不是什么（界面常驻诚实边界）
本工具为 **100% 本机离线运行的确定性度量与辅助分析仪器**，不上传任何用户数据。所有统计、敏感凭证嗅探与高亮均基于公开透明的数学与编码规则，结果供排查与核验参考。

---

## 🚀 30 秒“诶”点（首次启动自动演示）
启动即在 12 条内置考古时间轴记录中精准揪出 3 处高敏凭证：
1. **银行卡号**：经由真实 Luhn 模 10 奇偶加权求和校验并排除全同测试号；
2. **OpenAI / AWS 密钥**：精准嗅探 API Key 与 Access Token 结构；
3. **高香农信息熵随机密码串**：通过真实信息熵公式 $H = -\sum p_i \log_2 p_i$ 捕获 $H \ge 3.85$ 的极高危复杂口令。

支持右侧一键脱敏复制（保留前 3 后 2，中间自动替换为 `••••••`）。

---

## 📦 架构与构建

- **前端架构**：React 19 + TypeScript + 现代深色仪器风格工作台；
- **桌面容器**：Electron 34 + Electron Forge (Squirrel)；
- **算法域**：`src/domain/clipboard-audit.cjs` 与 `src/domain/clipboard-audit.d.cts`（100% 确定性无副作用真实算法实现）；
- **单测基线**：Node 内置测试运行器 `node --test tests/*.test.cjs`，含 2 项反向对照测试。
